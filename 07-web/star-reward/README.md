## 一、这是什么

一个给两个孩子（王学为 / 王学宜）用的**星星奖励工作台**：完成任务加星、兑换扣星、日志全程可查、分类统计饼图。单文件 HTML，手机电脑都能用，手机可"添加到主屏幕"当 APP。

界面已去掉"宝宝"字样，标题显示"工作台 v14"。

核心能力：
- **儿童模式**（免密码）：预设任务一键完成加星 / 预设兑换一键扣星 / 看日志 / 看统计
- **家长模式**（4 位密码，默认 1234）：管理预设任务/预设兑换（增删、**改名**、改星改分类，重名禁止（改名也查重））、管理分类、改密码、重置 / 恢复出厂（均二次确认）、**日志可删除（星星自动退回/补回）**
- **云端多设备同步**：**数据库是唯一真源**。所有操作先写云端、成功才生效；**可见时 3 秒轮询 + 打开/聚焦页面立即拉取**（后台标签页自动暂停），A 改/导入 → B 自动跟着变
- **数据安全**：首屏可导出 JSON / Excel 备份、导入恢复（完全覆盖式）；断网时操作会被拒绝（不做离线记录）

## 四、数据安全机制说明（数据库唯一真源）

1. **数据库唯一真源**：浏览器不保存任何数据副本（无本地数据缓存）。页面每次打开/可见时每 3 秒轮询、**打开或切回页面立即拉取**，把云端数据**整体拉取并替换**显示——设备只是"显示器"，不存在"本地与云端不一致"（后台标签页暂停轮询，浏览器本身也会对隐藏页强制降频，节省云端配额）
2. **写先云端、失败即拒**：加星/兑换/分类/密码/重置/导入等所有操作，都是**先写云端、成功才更新界面**；失败提示"网络错误"且不生效。断网时无法读写，页面顶部显示"无法连接云端（操作会被拒绝）"，首屏失败会显示"重试"按钮
3. **跨设备一致性**：A 在任何设备上改/删/导入 → 云端变化 → 其他设备**可见时 3 秒内**（打开/切回页面立即）拉到新状态直接显示。设备没有本地数据可以"唱反调"——彻底消灭了此前"删除复活""导入不生效""旧状态传回来"这一整类问题
4. **导出备份**：首屏"导出 JSON"（完整数据）/ 设置里"导出 Excel"（当前娃日志）；"导入恢复"为**完全覆盖式**（分类、日志、密码全部替换成备份内容），导入前请先导出；**备份里没有日志时会警告**，防止误导空备份清空数据
5. **100 次累加验证**：设置页按钮，真实云端串行读写 100 次验证可靠性
6. ⚠️ **代价（用户已确认接受）**：断网时不能记录星星（会提示网络错误）；打开页面需要联网

## 五、恢复与使用指引

### 日常使用
1. 手机浏览器打开部署链接 → 「分享/更多」→「添加到主屏幕」→ 像 APP 一样用
2. 打开页面即从云端拉取最新数据（需联网）；两个娃可独立记录
3. 建议每 30 条左右导出一次 JSON 备份（首屏按钮）

### 页面打不开 / 链接失效
1. 直接双击 `工作台.html` 打开（需联网，数据从云端同步）
2. 若需重新部署：把最新 `工作台.html` 复制为 `deploy_baby/index.html`，重新部署到 CloudStudio（同一工作区则链接不变）
3. 若云端配置丢失：按第三节重建 Supabase 表结构与命名空间即可（行内容会由页面首次使用自动重建种子）

### 恢复历史数据
- 有 JSON 备份 → 打开页面 → 首屏「导入恢复」
- 无备份但云端在 → 打开页面即自动同步，无需操作

## 六、已知限制

1. **必须联网**：断网时无法读取/写入（页面提示"无法连接云端"），这是数据库唯一真源的既定取舍（用户已确认接受）
2. **多人同时改同一份配置**（如两台设备同时编辑分类）：最后写入者胜（单家庭场景影响极小）
3. 部署链接为公网可访问：任何拿到链接的人都能打开；页面不预填真实隐私数据
4. 密码机制是防误触，非强安全（4 位数字，云端明文存储）
