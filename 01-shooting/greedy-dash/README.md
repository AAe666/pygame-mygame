# 🚀 Greedy Dash（贪逼牛逼）- 竖屏射击小游戏

作者：**波斯睫毛**

一款使用 **Python + Pygame** 打造的竖屏固定屏自动射击 + Boss 战 + 轻度 Roguelite 成长游戏。
屏幕左侧是宝箱区，右侧是怪物区；你操控底部的一队飞船单位，**自动向上射击**——
打宝箱拿成长奖励，打怪物求生存，清波后迎战强力 BOSS。所有画面均由 `pygame.draw` /
`pygame.gfxdraw` 即时绘制，**不加载任何外部图片**。

- 英文名：**Greedy Dash**（窗口标题 / 工程名）
- 中文名：**贪逼牛逼**（仅作为打包后的 exe 文件名）

## 🎮 游戏玩法

- **目标**：通过全部波次。每波先清空右侧下落的怪物，清空后**登场一位 BOSS**，
  击败 BOSS 才算通过当前波；击败最后一关 BOSS 即通关结算。
- **四难度**：简单 / 普通 / 困难 = **10 关**；噩梦 = **11 关**（含压轴 BOSS 终焉之主）。
- **主菜单**：启动后进入主菜单，选择难度开始或查看游戏说明。
- **鼠标实时操控**：移动鼠标控制单位队列**左右平移**（实时贴合，无延迟），Y 固定在底部。
- **自动射击**：每个存活单位（含临时分身）独立向上发射子弹，攻击力与射速全队共享。
- **左侧打宝箱**：射击宝箱拿成长奖励（攻击力 / 攻速）。BOSS 战期间宝箱会**隐藏**，防止恶意刷宝箱。
- **底线生存**：怪物一旦纵向抵达玩家所在行，随机击杀一个单位（护盾优先抵消）——无法靠躲角落苟活。
- BOSS 子弹命中玩家同样等同于一次触底伤害（无敌/护盾/分身可抵消）。
- **暂停 / 重开**：左上角暂停按钮或 `ESC` 暂停；暂停 / 结算界面均有按钮可选。
- **失焦自动暂停**：点击其他窗口或最小化时自动暂停；鼠标单纯移出窗口不暂停。

## 🕹️ 操作方式

| 操作 | 方式 |
|------|------|
| 队列左右平移 | 移动鼠标（横向跟随，Y 固定） |
| 暂停 / 继续 | 点击左上角暂停按钮 或 `ESC` |
| 暂停时重新开始 | 暂停界面点击「重新开始」按钮（当前难度） |
| 返回主菜单 | 暂停 / 结算界面点击「返回主菜单」按钮 |
| 使用无敌道具 | 持有无敌道具时点击**鼠标左键** |
| 释放分身道具 | 持有分身道具时点击**鼠标右键** |
| 结束/通关后重开 | 点击界面「重新开始 / 再来一局」按钮 |
| 游戏说明翻页 | 说明界面点击「上一页 / 下一页」或 ←/→ 键 |

游戏启动后进入主菜单，选择难度即玩；单位自动开火，你只需专注走位、取舍与 BOSS 战。

## 🎁 宝箱奖励

### 小宝箱（左侧固定 10 个，击破后 5 秒重生）
| 奖励 | 概率 | 效果 |
|------|------|------|
| 攻击力 | 70% | `+ attack_bonus(波次-1)` |
| 攻速 | 30% | 射击间隔缩短（叠加） |

攻击力增量序列 `attack_bonus(tier)`（tier = 波次-1）：
**1, 1, 1.5, 1.5, 2, 2, 2.5, 3, 3, 4**（支持小数，不取整）。

### 大宝箱（每波 1 个，从顶部缓慢下落，触底消失无奖励）
| 奖励 | 权重 | 效果 |
|------|------|------|
| 攻击增幅 | 25 | 小宝箱攻击力增量 × 2 |
| 超载火力 | 25 | 小宝箱攻速规则 × 2 |
| 获得护盾 | 15 | 随机存活单位加护盾（优先抵消撞击） |
| 召唤分身 | 20 | 获得「分身」道具（存入道具槽，右键释放，召唤持续 3 秒的临时分身） |
| 获得无敌 | 15 | 获得「无敌」道具（存入道具槽，左键使用） |

> 护盾已满时，护盾的 15% 并入攻击增幅；无敌已持有时，无敌的 15% 并入攻击增幅。

## 🛡️ 道具说明

### 护盾
随机给一个存活单位加淡蓝保护罩，被撞时**优先消耗护盾**而非单位，抵消一次伤害。

### 临时分身（3 秒）
大宝箱「召唤分身」奖励产出，存入**左上角分身道具槽**（无敌槽下方，双菱形图标）。
- 持有时槽内显示紫色脉动双菱形，空槽为暗紫圆圈。
- 点击**鼠标右键**释放：召唤一个持续 3 秒的临时分身，排布在主队列两侧，**自动开火**（共享攻击力）。
- 分身可被 BOSS 子弹击中销毁（替挡一次）。仅可持有一个；重复拾取时其权重并入攻击增幅。

### 无敌（3 秒）
大宝箱「获得无敌」奖励产出，存入**左上角无敌道具槽**（暂停键下方，五角星图标）。
- 持有时槽内显示金色脉动五角星，空槽为暗金圆圈。
- 点击**鼠标左键**使用：进入 **3 秒无敌**。
- 无敌期间：玩家单位闪烁；屏幕四周出现金色脉动边框；BOSS 子弹与怪物触底均不造成伤害（怪物仍被挡下消失）。
- 仅可持有一个；重复拾取时其权重并入攻击增幅。

## 👹 BOSS 系统（11 关 11 BOSS）

每波清怪后，BOSS **登场过场动画**（约 2 秒，居中放大展示外观 + 霓虹名字，期间游戏暂停，
类似《霓虹深渊》），结束后 BOSS 移至顶部开战。BOSS **不下落**，发射子弹攻击玩家；
**血量 = 该波怪物血量 × 倍率**（倍率随难度：简单 **×100** / 普通 **×140** / 困难 **×170** / 噩梦 **×200**）。

### 阶段触发（由难度决定）
- **简单 / 普通**：仅二阶段，血量 **50%** 触发。
- **困难 / 噩梦**：三阶段，血量 **70%** 触发二阶段、**40%** 触发三阶段（新形象 + 新机制）。

> BOSS 子弹命中玩家 = 一次触底伤害；无敌/护盾/分身可抵消。BOSS 死亡后清场，进入下一波或通关。

### BOSS 一览（顺序按机制难度从简到难）

| 关 | BOSS | 机制 | 一阶段 | 二阶段 | 三阶段（仅困难/噩梦） |
|----|------|------|--------|----|----|
| 1 | 裂隙之眼 | 扇形散射 | 闭眼蓄力 → 3 发扇形 | 5 发扇形 + 快速直瞄弹 | 血眸全开：8 发全向散射 + 连续 3 发预测直瞄，节奏加快 |
| 2 | 双生幻影 | 移动综合 | 双核横移夹击瞄准弹 + 周期汇聚弹 | 合体为单核：环形 + 扇形 + 召唤综合弹幕 | 四相幻影：分裂 4 小核环绕各自瞄准 + 周期合体爆裂环形 |

## 📊 数值（四难度）

怪物血量公式：`HP(w) = (2 + d + d²) × (1 + LIN·d + QUAD·d²)`，`d = w-1`，第 1 波 = 2。
小宝箱血量 = 怪物 × 5；大宝箱血量 = 怪物 × 12；BOSS 血量 = 怪物 × 倍率（随难度：简单 100 / 普通 140 / 困难 170 / 噩梦 200）。
怪物数量（四难度一致）：`12 + (w-1) × 2`（噩梦第 11 关 = 32）。

### 四难度差异
| 难度 | 血量曲线 LIN/QUAD | 总波数 | BOSS 阶段 | BOSS 血量倍率 |
|------|------|------|------|------|
| 简单 | 0.45 / 0.15 | 10 | 二阶段(50%) | ×100 |
| 普通 | 0.6 / 0.2 | 10 | 二阶段(50%) | ×140 |
| 困难 | 0.75 / 0.25 | 10 | 三阶段(70%/40%) | ×170 |
| 噩梦 | 0.9 / 0.32 | 11 | 三阶段(70%/40%) | ×200 |

> BOSS 血量倍率**随难度不同**：简单 ×100 / 普通 ×140 / 困难 ×170 / 噩梦 ×200。
> 其余参数（怪物基础数量 12 / 步进 2、玩家初始射速 0.30s、
> BOSS 普通子弹 200 / 快速 320、小/大宝箱倍率 5/12、单位上限 4、金身 3s、分身 3s）**四难度完全一致**。

## 🏆 通关结算 / 失败界面

- **通关**：击败最后一关 BOSS 后进入结算界面，展示游戏时间、击杀怪物、击败 BOSS 数、
  击破小/大宝箱数、最终属性（攻击力、射速/秒、存活单位、宝箱等级）。按钮：**再来一局** / **返回主菜单**。
- **失败**：所有单位阵亡后进入失败界面，复用结算统计面板（标题「游戏失败」，显示坚持到第几波）。
  按钮：**重新开始（同难度）** / **返回主菜单**。
- **暂停界面**：三按钮——继续游戏 / 重新开始（当前难度） / 返回主菜单。

## 🗂️ 项目结构

```
greedy-dash/
├── settings.py          # 全局配置与常量（窗口、颜色、四难度系统、BOSS/道具参数）
├── gamedoc.py           # 游戏说明数据源（玩法/操作/宝箱/道具/BOSS/数值表，与 README 同步）
├── player.py            # 玩家单位组（本体+临时分身、移动、射击、护盾、金身无敌）
├── enemy.py             # 小宝箱 Chest / 怪物 Monster / 大宝箱 BigChest
├── boss.py              # BOSS 系统：子弹 + 横扫激光 + 基类 + 11 个 BOSS + 工厂
├── particle.py          # 粒子系统（星光、尾焰、拖尾、爆炸、击破）
├── ui.py                # 主菜单、游戏说明、暂停、HUD、BOSS 出场、结算（通关/失败）、浮动文字
├── main.py              # 主程序（循环、状态机、碰撞、输入、失焦暂停）
├── GreedyDash.spec      # PyInstaller 打包配置（→ 贪逼牛逼.exe）
├── requirements.txt     # 依赖清单
├── start.bat            # Windows 一键启动脚本
└── README.md            # 本文档
```
