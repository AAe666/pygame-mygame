# 🚀 Greedy Dash（贪逼牛逼）- 竖屏射击小游戏

一款使用 **Python + Pygame** 打造的竖屏固定屏自动射击 + 轻度 Roguelite 底线生存游戏。
屏幕左侧是宝箱区，右侧是怪物区；你操控底部的一队飞船单位，**自动向上射击**——
打宝箱拿成长奖励，打怪物求生存。所有画面均由 `pygame.draw` / `pygame.gfxdraw` 即时绘制，
**不加载任何外部图片**。

- 英文名：**Greedy Dash**（窗口标题 / 工程名）
- 中文名：**贪逼牛逼**（仅作为打包后的 exe 文件名）

## 🎮 游戏特色

- **单位组机制**：初始 1 个本体，通过宝箱最多扩充到 4 个单位（本体 + 分身），全队共享攻击力与射速。
- **鼠标实时操控**：队列中心 x **实时贴合鼠标**（无速度限制），Y 固定在底部；严格限制在屏幕内。
- **宝箱系统（小宝箱）**：左侧固定 10 个，击破后延迟 5 秒重生，血量随波次提升。
  - 奖励概率：**攻击力 70% / 攻速 30%**（单位满员时攻速分支回退为攻击力）。
- **大宝箱**：分割线左边右半部生成、最多 1 个、进波重置；从顶部缓慢下落（40px/s），触底消失无奖励。
  - 击破给加权随机奖励（见下方「奖励概率」），伴随金色粒子爆发 + 屏幕闪白 + 居中提示。
- **波次机制**：右侧怪物从顶部成波涌下，数量与血量随波次递增；怪物清空后**立即进入下一波**（无清波等待），首只同帧生成。
- **并排成群**：每只怪物有概率并排出现（5% 三个 / 10% 两个 / 85% 单个），受本波剩余名额与屏幕空间限制。
- **底线生存**：怪物一旦纵向抵达玩家所在行（无论横向位置），就随机击杀一个单位——无法靠躲角落无限苟活。
- **护盾**：随机单位获得淡蓝保护罩，可抵消一次撞击且**优先被消耗**。
- **暂停 / 重开**：左上角科幻风暂停按钮或 `ESC` 暂停；游戏结束点「重新开始」按钮重开（无键盘 R 重开）。
- **失焦自动暂停**：点击其他窗口或最小化时自动暂停；鼠标单纯移出窗口**不**暂停。
- **炫酷视觉**：深紫→深蓝渐变背景 + 50 颗星光、飞船光晕尾焰、宝箱脉动金光、怪物多刺红晕、
  子弹三层叠加 `BLEND_ADD` 光球与拖尾残影、HUD 数值弹跳、大宝箱旋转光环。

## 🕹️ 操作方式

| 操作 | 方式 |
|------|------|
| 队列左右平移 | 移动鼠标（横向跟随，Y 固定） |
| 暂停 / 继续 | 点击左上角暂停按钮 或 `ESC` |
| 重新开始 | 游戏结束后点击「重新开始」按钮 |

游戏**启动即玩**，无需菜单；单位自动开火，你只需专注走位与取舍。

## 🎯 奖励概率

### 小宝箱
| 奖励 | 概率 | 效果 |
|------|------|------|
| 攻击力 | 70% | `+ attack_bonus(波次//4)` |
| 攻速 | 30% | 射击间隔缩短（叠加） |

攻击力增量序列 `attack_bonus(tier) = 1 + tier*(tier+1)/2`（tier = 波次//4）：
**1, 2, 4, 7, 11, 16, 22**（每 4 波升一档，相邻差值 1,2,3,4,5,6）。

### 大宝箱（加权随机）
| 状态 | 攻击增幅 | 超载火力 | 护盾 | 分身 |
|------|------|------|------|------|
| 护盾可用 | 40% | 25% | 15% | 20% |
| 护盾已满 | 55% | 25% | —（并入攻击增幅） | 20% |

- **攻击增幅** = 小宝箱攻击力增量 × 2。
- **超载火力** = 小宝箱攻速规则 × 2。
- **护盾** = 随机存活单位获得护盾（优先抵消撞击）。
- **分身** = 新增一个单位（满员则回退为攻击增幅）。

## 📊 数值（随波次变化）

怪物血量公式：`HP(w) = (2 + (w-1) + (w-1)²) × (1 + 0.6×(w-1))`，第 1 波 = 2。
小宝箱血量 = 怪物 × 5；大宝箱血量 = 怪物 × 12。

| 波次 | 怪物血 | 小宝箱血(×5) | 大宝箱血(×12) | 怪物数量 |
|------|------|------|------|------|
| 1 | 2 | 10 | 24 | 8 |
| 2 | 6 | 30 | 72 | 10 |
| 3 | 18 | 90 | 216 | 12 |
| 4 | 39 | 195 | 468 | 14 |
| 5 | 75 | 375 | 900 | 16 |
| 6 | 128 | 640 | 1536 | 18 |
| 7 | 202 | 1010 | 2424 | 20 |
| 8 | 302 | 1510 | 3624 | 22 |

> 难度系数 `DIFFICULTY_STEP = 0.6`：第 1 波不变，第 2 波起每波血量乘数 +60%（可调）。

```
01-shooting/
└── greedy-dash/                # 工程目录（与 02-simulation、03-music 并列）
    ├── settings.py                # 全局配置与常量（窗口、颜色、数值平衡）

    ├── particle.py              # 粒子系统（星光、尾焰、拖尾、爆炸、击破）
    ├── ui.py                    # 暂停按钮/遮罩、波次提示、HUD、游戏结束、浮动文字
    ├── main.py                  # 主程序（游戏循环、波次状态机、碰撞、输入、失焦暂停）

    ├── start.bat               # Windows 一键启动脚本
    ├── README.md               # 本文档
    └── venv/                 # Python 虚拟环境
```

## 📦 打包为 EXE（Windows）

本工程使用 **PyInstaller** 打包成单个可独立运行的 `贪逼牛逼.exe`，无需目标机器安装 Python。

### 1. 安装 PyInstaller
```bash
venv\Scripts\activate
pip install pyinstaller
```

### 2. 执行打包
```bash
cd d:\TYW\Code\Games\01-shooting\greedy-dash
venv\Scripts\activate
venv\Scripts\python.exe -m PyInstaller GreedyDash.spec
```

> `GreedyDash.spec` 内部已配置 `console=False`（无控制台窗口）、`name='贪逼牛逼'`（中文 exe 文件名）
> 与必要的 `hiddenimports`，等价于 `pyinstaller --onefile --noconsole --name=贪逼牛逼 main.py`。

### 3. 获取结果
打包完成后，exe 位于 `dist/贪逼牛逼.exe`，可直接发送给他人双击运行。

> 提示：若系统未安装 Visual C++ 运行库导致启动报错，请安装
> [Microsoft Visual C++ Redistributable](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist)。
