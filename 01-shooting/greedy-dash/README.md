# 🚀 Greedy Dash（贪逼牛逼）- 竖屏射击小游戏

作者：**波斯睫毛**

一款使用 **Python + Pygame** 打造的竖屏固定屏自动射击 + Boss 战 + 轻度 Roguelite 成长游戏。
屏幕左侧是宝箱区，右侧是怪物区；你操控底部的一队飞船单位，**自动向上射击**——
打宝箱拿成长奖励，打怪物求生存，清波后迎战强力 BOSS。所有画面均由 `pygame.draw` /
`pygame.gfxdraw` 即时绘制，**不加载任何外部图片**。

- 英文名：**Greedy Dash**（窗口标题 / 工程名）
- 中文名：**贪逼牛逼**（仅作为打包后的 exe 文件名）

## 🎮 游戏玩法

- **目标**：通过全部波次。每波先清空右侧下落的怪物，清空后**登场一位 BOSS**，
  击败 BOSS 才算通过当前波；击败最后一关 BOSS 即通关结算。
- **四难度**：简单 / 普通 / 困难 = **10 关**；噩梦 = **11 关**（含压轴 BOSS 终焉之主）。
- **主菜单**：启动后进入主菜单，选择难度开始或查看游戏说明。
- **鼠标实时操控**：移动鼠标控制单位队列**左右平移**（实时贴合，无延迟），Y 固定在底部。
- **自动射击**：每个存活单位（含临时分身）独立向上发射子弹，攻击力与射速全队共享。
- **左侧打宝箱**：射击宝箱拿成长奖励（攻击力 / 攻速）。BOSS 战期间宝箱会**隐藏**，防止恶意刷宝箱。
- **底线生存**：怪物一旦纵向抵达玩家所在行，随机击杀一个单位（护盾优先抵消）——无法靠躲角落苟活。
- BOSS 子弹命中玩家同样等同于一次触底伤害（无敌/护盾/分身可抵消）。
- **暂停 / 重开**：左上角暂停按钮或 `ESC` 暂停；暂停 / 结算界面均有按钮可选。
- **失焦自动暂停**：点击其他窗口或最小化时自动暂停；鼠标单纯移出窗口不暂停。

## 🕹️ 操作方式

| 操作 | 方式 |
|------|------|
| 队列左右平移 | 移动鼠标（横向跟随，Y 固定） |
| 暂停 / 继续 | 点击左上角暂停按钮 或 `ESC` |
| 暂停时重新开始 | 暂停界面点击「重新开始」按钮（当前难度） |
| 返回主菜单 | 暂停 / 结算界面点击「返回主菜单」按钮 |
| 使用无敌道具 | 持有无敌道具时点击**鼠标左键** |
| 释放分身道具 | 持有分身道具时点击**鼠标右键** |
| 结束/通关后重开 | 点击界面「重新开始 / 再来一局」按钮 |
| 游戏说明翻页 | 说明界面点击「上一页 / 下一页」或 ←/→ 键 |

游戏启动后进入主菜单，选择难度即玩；单位自动开火，你只需专注走位、取舍与 BOSS 战。

## 🎁 宝箱奖励

### 小宝箱（左侧固定 10 个，击破后 5 秒重生）
| 奖励 | 概率 | 效果 |
|------|------|------|
| 攻击力 | 70% | `+ attack_bonus(波次-1)` |
| 攻速 | 30% | 射击间隔缩短（叠加） |

攻击力增量序列 `attack_bonus(tier)`（tier = 波次-1）：
**1, 1, 1.5, 1.5, 2, 2, 2.5, 3, 3, 4**（支持小数，不取整）。

### 大宝箱（每波 1 个，从顶部缓慢下落，触底消失无奖励）
| 奖励 | 权重 | 效果 |
|------|------|------|
| 攻击增幅 | 25 | 小宝箱攻击力增量 × 2 |
| 超载火力 | 25 | 小宝箱攻速规则 × 2 |
| 获得护盾 | 15 | 随机存活单位加护盾（优先抵消撞击） |
| 召唤分身 | 20 | 获得「分身」道具（存入道具槽，右键释放，召唤持续 3 秒的临时分身） |
| 获得无敌 | 15 | 获得「无敌」道具（存入道具槽，左键使用） |

> 护盾已满时，护盾的 15% 并入攻击增幅；无敌已持有时，无敌的 15% 并入攻击增幅。

## 🛡️ 道具说明

### 护盾
随机给一个存活单位加淡蓝保护罩，被撞时**优先消耗护盾**而非单位，抵消一次伤害。

### 临时分身（3 秒）
大宝箱「召唤分身」奖励产出，存入**左上角分身道具槽**（无敌槽下方，双菱形图标）。
- 持有时槽内显示紫色脉动双菱形，空槽为暗紫圆圈。
- 点击**鼠标右键**释放：召唤一个持续 3 秒的临时分身，排布在主队列两侧，**自动开火**（共享攻击力）。
- 分身可被 BOSS 子弹击中销毁（替挡一次）。仅可持有一个；重复拾取时其权重并入攻击增幅。

### 无敌（3 秒）
大宝箱「获得无敌」奖励产出，存入**左上角无敌道具槽**（暂停键下方，五角星图标）。
- 持有时槽内显示金色脉动五角星，空槽为暗金圆圈。
- 点击**鼠标左键**使用：进入 **3 秒无敌**。
- 无敌期间：玩家单位闪烁；屏幕四周出现金色脉动边框；BOSS 子弹与怪物触底均不造成伤害（怪物仍被挡下消失）。
- 仅可持有一个；重复拾取时其权重并入攻击增幅。

## 👹 BOSS 系统（11 关 11 BOSS）

每波清怪后，BOSS **登场过场动画**（约 2 秒，居中放大展示外观 + 霓虹名字，期间游戏暂停，
类似《霓虹深渊》），结束后 BOSS 移至顶部开战。BOSS **不下落**，发射子弹攻击玩家；
**血量 = 该波怪物血量 × 倍率**（倍率随难度：简单 **×100** / 普通 **×140** / 困难 **×170** / 噩梦 **×200**）。

### 阶段触发（由难度决定）
- **简单 / 普通**：仅二阶段，血量 **50%** 触发。
- **困难 / 噩梦**：三阶段，血量 **70%** 触发二阶段、**40%** 触发三阶段（新形象 + 新机制）。

> BOSS 子弹命中玩家 = 一次触底伤害；无敌/护盾/分身可抵消。BOSS 死亡后清场，进入下一波或通关。

## 📊 数值（四难度）

怪物血量公式：`HP(w) = (2 + d + d²) × (1 + LIN·d + QUAD·d²)`，`d = w-1`，第 1 波 = 2。
小宝箱血量 = 怪物 × 5；大宝箱血量 = 怪物 × 12；BOSS 血量 = 怪物 × 倍率（随难度：简单 100 / 普通 140 / 困难 170 / 噩梦 200）。
怪物数量（四难度一致）：`12 + (w-1) × 2`（噩梦第 11 关 = 32）。

### 四难度差异
| 难度 | 血量曲线 LIN/QUAD | 总波数 | BOSS 阶段 | BOSS 血量倍率 |
|------|------|------|------|------|
| 简单 | 0.45 / 0.15 | 10 | 二阶段(50%) | ×100 |
| 普通 | 0.6 / 0.2 | 10 | 二阶段(50%) | ×140 |
| 困难 | 0.75 / 0.25 | 10 | 三阶段(70%/40%) | ×170 |
| 噩梦 | 0.9 / 0.32 | 11 | 三阶段(70%/40%) | ×200 |

> BOSS 血量倍率**随难度不同**：简单 ×100 / 普通 ×140 / 困难 ×170 / 噩梦 ×200。
> 其余参数（怪物基础数量 12 / 步进 2、玩家初始射速 0.30s、
> BOSS 普通子弹 200 / 快速 320、小/大宝箱倍率 5/12、单位上限 4、金身 3s、分身 3s）**四难度完全一致**。

## 🏆 通关结算 / 失败界面

- **通关**：击败最后一关 BOSS 后进入结算界面，展示游戏时间、击杀怪物、击败 BOSS 数、
  击破小/大宝箱数、最终属性（攻击力、射速/秒、存活单位、宝箱等级）。按钮：**再来一局** / **返回主菜单**。
- **失败**：所有单位阵亡后进入失败界面，复用结算统计面板（标题「游戏失败」，显示坚持到第几波）。
  按钮：**重新开始（同难度）** / **返回主菜单**。
- **暂停界面**：三按钮——继续游戏 / 重新开始（当前难度） / 返回主菜单。

## 📱 移动端移植（Android）

代码层面已完成移动端就绪改造，**可直接编译为 Android APK**。核心改造如下：

- **虚拟分辨率 + 信箱化（letterbox）**：游戏始终以固定 `480×720` 虚拟分辨率绘制，
  再等比缩放居中贴到真实屏幕，两侧/上下用黑边填充，绝不拉伸变形。
  PC 上窗口即 `480×720`（缩放 = 1，无黑边）；手机全屏后自动信箱化适配竖屏。
- **触摸识别**：首次收到 `FINGERDOWN` 事件即进入触摸模式（`touch_mode=True`）。
- **技能改点图标释放**：移动端没有左右键，改为**点击左上角「无敌 / 分身」图标**释放技能
  （PC 上仍兼容左键/右键任意处释放）。飞船跟随手指拖动（触摸映射到鼠标移动事件）。
- **无键盘环境**：作弊码 `bosijiemao`、调试模式（连按 D）依赖键盘，**在手机上不会触发**
  （相关代码保留但无害，不影响玩法）。

### 移动端操作

| 队列左右平移 | 手指在屏幕任意位置**拖动**（飞船实时跟随手指横向位置） |

### 打包为 APK（Android）

Windows 无法直接编译 APK，需在 **Linux 或 WSL（Ubuntu，必须是 WSL2）** 中使用 `buildozer`
（底层 `python-for-android`）完成。iOS 则需 macOS。

> ⚠️ **必须用 WSL2，不能用 WSL1**：WSL1 的内核无法 `execve` NDK 自带的 clang，会报
> `Exec format error`，导致 jpeg/pygame 等原生配方编译失败。若当前是 WSL1，先在 Windows 管理员
> PowerShell 执行 `wsl --update` 再 `wsl --set-version Ubuntu 2` 升级到 WSL2。

#### 首次构建（一键脚本，较慢，约 20–60 分钟）

项目根目录的 `build_android.sh` 会：装系统依赖 → 建虚拟环境装 buildozer → 把源码从 `/mnt/d`
（Windows 文件系统，权限受限）复制到 WSL 家目录 `~/greedy-dash-build`（原生 ext4）→ `buildozer android debug`。

```bash
# Windows 管理员 PowerShell：先确认/升级到 WSL2，再在 Ubuntu 终端里运行
bash /mnt/d/TYW/Code/Games/01-shooting/greedy-dash/build_android.sh
```

产物：`~/greedy-dash-build/bin/greedydash-4.0.0-arm64-v8a-debug.apk`。
首次会下载 Android SDK/NDK 并编译 hostpython3、jpeg、SDL2、pygame 等原生库，耗时主要在编译。

#### 改代码后增量重打（推荐，很快，几分钟）

> 只改 Python 游戏代码（main.py / ui.py / boss.py 等）时，**不要重跑 `build_android.sh`**
> （它会 `rm -rf ~/greedy-dash-build` 清掉已编译缓存，从头再来）。原生库已缓存，只需重打包。

```bash
# 在 WSL 里：把 Windows 上改好的源码同步进构建目录（* 不会动 .buildozer 缓存）
cp -r /mnt/d/TYW/Code/Games/01-shooting/greedy-dash/* ~/greedy-dash-build/

source ~/venv_buildozer/bin/activate
cd ~/greedy-dash-build
buildozer android debug
```

新 APK 覆盖 `~/greedy-dash-build/bin/greedydash-4.0.0-arm64-v8a-debug.apk`。
（只同步改动用 `cp` 即可；若要连删除也同步，用
`rsync -a --exclude='.buildozer' /mnt/d/TYW/Code/Games/01-shooting/greedy-dash/ ~/greedy-dash-build/`）

#### 把 APK 拷回 Windows 项目根目录（方便取用 / 提交）

```bash
cp ~/greedy-dash-build/bin/greedydash-*.apk /mnt/d/TYW/Code/Games/01-shooting/greedy-dash/
```

之后在资源管理器打开 `D:\TYW\Code\Games\01-shooting\greedy-dash\` 即可拿到 APK；
手机开启 USB 调试后可用 `adb install greedydash-4.0.0-arm64-v8a-debug.apk` 安装（debug 签名可直接装）。

#### 踩坑提示（首次构建可能遇到）

- 编译 hostpython3 前需 `sudo apt install -y libssl-dev`，否则 pip 无 SSL 模块、下不了依赖。
- p4a 不会自动装 Cython：需给 hostpython3 手动装 `Cython>=3.1,<4`
  （hostpython3 是 Python 3.14，需 Cython≥3.1），否则 pygame 的 `build_ext` 报缺 Cython。
- Gradle Wrapper 会联网下 `gradle-8.14.3-all.zip`，WSL 连不上时把手动下载的 zip 放到
  `~/.gradle/wrapper/dists/gradle-8.14.3-all/<hash>/` 即可离线。
- 若 pygame 配方编译报错，把 `buildozer.spec` 里 `requirements = python3,pygame==2.5.2`
  的 `pygame==2.5.2` 改成 `pygame==2.1.2` 重试。

#### 配置要点

- `buildozer.spec` 已设 `orientation = portrait`（竖屏）、`android.archs = arm64-v8a`、
  `requirements = python3,pygame==2.5.2`、`source.include_exts = py,png,jpg,ico,ttf,...`。
- 游戏已用 `ANDROID_ARGUMENT` 自动识别安卓并全屏，无需额外改代码。
- **内置中文字体**：`fonts/simhei.ttf` 随包打入，`ui.get_font` 优先加载，Android 中文不再变方框
  （PC 也统一用该字体）。若公开发布 APK，建议替换为 SIL 开源的 **Noto Sans SC** 等可自由分发字体
  （把字体放进 `fonts/` 并改 `ui._FONT_PATH`）。
